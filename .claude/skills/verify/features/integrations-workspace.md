# Integrations workspace

The `/settings/integrations` route hosts the five hardware-facing operator tabs: `现场网关` (gateway data chain and enrollment codes), `无线集中器` (`?view=concentrators` wireless temperature concentrator channels, RF/serial parameters, and 200-slot EID Flash table), `电表数据核对` (`?view=meters` valid vs suspect hourly energy reconciliation), `传感器校准` (`?view=sensors` probe offset suggestions and calibration due dates), and `OTA 升级` (`?view=ota` edge gateway OTA package registry, canary rollout orchestration, live polling detail sheet, pause/resume, and confirmed rollback).

## Sub-features

- `integrations-gateway-chain` displays the 5-stage data chain (`现场设备` → platform), active gateway cards (`EG8200-*`), issued gateway certificates, lossless key rotation, single-certificate revocation, gateway config shadow inspection/editing (`UNCONFIGURED` / `PENDING_SYNC` / `SYNCED` / `DRIFTED`, declarative Modbus driver register tables `协议驱动点表`, edge offline autonomy policies `断网自治策略`, drift details including `DRIVER_CONFIGS`/`AUTONOMY_POLICY`, partial PUT updates & clearing, optimistic 409 conflict reload), bounded-TTL live packet capture (`通信抓包`) with direction/quarantine filtering, recent uplink quarantine records (`接收隔离` including `RATE_LIMITED` `上报速率超限`) with expandable payload inspection, and gateway stop/re-enable actions.
- `integrations-concentrators` inspects 23+ wireless temperature probe channels (`°C`, `mV`, `dBm`, low-battery & offline filters), edits 14 serial/LoRa RF parameters, manages paginated 200-slot EID mappings (`<= 50` DOM rows) with duplicate guard and batch fill, blocks protected RS485 UIDs `{2, 3, 4, 5, 10, 31}`, supports offline staging (`stageIfOffline` checkbox -> `STAGED_SHADOW` audit & config shadow invalidation), and persists Flash commits with required change reason + CSRF.
- `integrations-meter-reconciliation` contrasts valid and suspect energy deltas, toggles chart vs table views, opens the meter drawer, and creates deduplicated inspection work orders.
- `integrations-sensor-calibration` surfaces pump-steady-state probe zero-offset suggestions (marked unapplied), low-ΔT uncertainty bounds, and calibration work orders.
- `integrations-ota-rollout` lists signed OTA packages (`EDGE_GATEWAY` / `FIRMWARE`), uploads up to 64 MiB packages via multipart form with SemVer/arch/hardware model/SHA-256/Ed25519 validation, launches site- and tag-targeted canary campaigns (`canaryPercent`, `failureRateThresholdPct`, `healthCheckTimeoutSec`, `autoPromoteRollout`), highlights circuit-breaker auto-pauses (`FAILURE_RATE_THRESHOLD_EXCEEDED`), polls active campaign details (`?view=ota&inspect=<campaignId>`) with per-gateway progress bars, and supports pause, resume/promote, and checkbox-confirmed emergency rollback.

## How to get to it (user POV)

- Click `集成管理` in the sidebar, click the `集成管理 ›` link from System Overview, or follow a link from the top `data-gap-banner`.
- Navigate directly to `/settings/integrations?site=<SITE_ID>` (or with `&view=concentrators` / `&view=meters` / `&view=sensors` / `&view=ota`).

## Gotchas

- `integrations.spec.ts` injects fresh `evaluatedAt` / `sampledAt` timestamps dynamically via `refreshSnapshotsWithCalibrationSignals`; static fixtures alone appear stale without refreshing timestamps.
- Ensure horizontal overflow check (`scrollWidth > innerWidth`) passes on all five tabs after viewport layout edits.
