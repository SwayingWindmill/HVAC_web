Implementation authority remains the Surface specifications, product contracts, and authoritative runtime projections. The images define visual hierarchy, density, shell composition, information grouping, and interaction emphasis; they are not data contracts and must not override business semantics.

Two scope corrections are intentionally implemented in code rather than copied literally from the 04 image:

1. The operations summary does not reuse an unrelated `18 / 22` device population. It derives the displayed equipment-group running population from the same topology projection shown in the workspace and labels it `当前工作区范围`.
2. The contextual inspector does not project site-level data quality onto the selected equipment group. Site data quality remains explicitly site-scoped; the inspector only shows selected-object facts owned by the current projection.
