# 数字孪生

2026-10-15 与用户确认。站点的冷站和末端放进一个可以旋转、缩放、点选的 3D 场景，真实读数在场景里动起来；画面跟随设计系统 1.0（浅色为主，深色主题同步），参考 Dilum Sanjaya 的仓储演示（React + React Three Fiber，2026-10-04）。

## 范围

| 阶段 | 内容 |
| --- | --- |
| P1 | 冷端：冷水机组、冷却塔、冷冻泵、冷却泵、供回水总管与管路；实时读数、运行状态、管路流动；点选设备看详情 |
| P2 | 末端：建筑分层（可整栋看、可剥开单层），房间按温度着色，末端设备；冷冻水立管连接冷站与各层 |
| P3 | 告警在场景里闪烁并跳到告警、视角漫游、精细模型（Blender → glTF） |

松雅轩末端先按默认布局：1F 大厅（散台区）、前台、厨房；2F、3F 各 4 个大包间、6 个小包间；大厅 2 台空调箱，每个包间 1 台风机盘管。实际数量以后在站点文件里改。

## 决定

| 决策 | 结论 |
| --- | --- |
| 场景从哪来 | 按 Registry 生成，不在前端写站点布局：冷水机组、冷却塔、水泵来自已登记的资产（按类型分组、按编码排序），末端来自空间层级（建筑 → 楼层 → 房间）。有数据的资产显示实时状态，没有数据源的显示灰色「未接入」 |
| 读数从哪来 | 复用实时页的 `useRealtimePlant`（资产模型 + 快照 + 实时推送），不新增接口 |
| 什么在动 | 机组按自身运行状态（电表功率 > 5 kW）发亮；冷冻水管路在冷冻水泵（总管流量 > 10 m³/h）运行时流动；冷却水管路在任一机组运行时流动（机组运行必有冷却水循环，没有冷却水流量计）；水泵、冷却塔没有运行信号时静止并标「未接入」 |
| 技术 | React Three Fiber + drei（`docs/architecture/digital-twin-3d.md`）；设备先用程序化几何体，不加载模型文件 |
| 文案 | 场景标签和侧栏只用业务词，不显示编码、UUID |

## 性能（硬指标）

- 3D 代码只在进入「数字孪生」页时加载（路由级拆包）；其他页面的包体积不变。
- 静止时不重绘：没有流动、没有交互时按需渲染（`frameloop="demand"`），数据变化时才刷新一帧；有流动时才持续绘制。
- 像素比上限 1.5；重复的设备用实例化或共享几何体与材质；不加载贴图和模型文件。
- 页面隐藏或离开路由时停止绘制并释放 WebGL 资源。
- 验收：1440 宽度下首次进入页面到场景可交互 ≤ 2 s（本地网络），静止时 CPU 占用接近 0，3D 分包 gzip 后单独列出体积。

## 界面

- 路由 `/digital-twin`（站点范围，`?site=`），侧栏「运行」分组下，名称「数字孪生」。
- 场景铺满内容区；上方浮动指标：冷站总功率、制冷量、COP、室外温度与湿球温度；右侧点选详情复用设备页的设备侧栏（`?inspect=<id>`），未接入的资产显示名称与「未接入」。
- 视角按钮：全景 / 冷站 / 末端（P2 起加各楼层）。
- 深色主题下场景颜色取深色令牌。
