# 数字孪生

2026-10-15 与用户确认。站点的冷站和末端放进一个可以旋转、缩放、点选的 3D 场景，真实读数在场景里动起来；画面跟随设计系统 1.0（浅色为主，深色主题同步），参考 Dilum Sanjaya 的仓储演示（React + React Three Fiber，2026-10-04）。

## 范围

| 阶段 | 内容 |
| --- | --- |
| P1 | 沙盘：冷端（冷水机组、冷却塔、冷冻泵、冷却泵、总管与阀门）+ 末端楼宇（楼层剖切、外立面开关、空调箱 / 变风量末端 / 风机盘管 / 风管 / 风口）；实时读数、运行状态、管路流动；点选设备看详情 |
| P2 | 末端接入：房间温度着色、末端设备实时状态（需要 Registry 登记房间与末端设备） |
| P3 | 告警在场景里闪烁并跳到告警、视角漫游 |

松雅轩末端先按声明的布局（`twin-building.ts`）：1F 大厅、空调机房、后厨；2F、3F 各 4 个包间、4 个小包间和备餐间；大厅 1 台空调箱带 6 个变风量末端，每个包间 1 台风机盘管。Registry 还没有房间和末端设备，末端全部显示「未接入」；没有声明楼宇的站点只显示冷端。

## 决定

| 决策 | 结论 |
| --- | --- |
| 场景从哪来 | 冷端按 Registry 生成：冷水机组、冷却塔、水泵来自已登记的资产（按类型分组、按编码排序），机房大小随台数变化。末端楼宇暂由站点声明（`BUILDING_PLANS[site.code]`），Registry 有了空间层级和末端设备后改为按 Registry 生成。有数据的资产显示实时状态，没有数据源的标「未接入」，不转、不亮 |
| 读数从哪来 | 复用实时页的 `useRealtimePlant`（资产模型 + 快照 + 实时推送），不新增接口 |
| 什么在动 | 机组按自身运行状态（电表功率 > 5 kW）发亮；冷冻水管路在冷冻水泵（总管流量 > 10 m³/h）运行时流动；冷却水管路在任一机组运行时流动（机组运行必有冷却水循环，没有冷却水流量计）；水泵、冷却塔没有运行信号时静止并标「未接入」 |
| 技术 | React Three Fiber + drei + @react-three/postprocessing（`docs/architecture/digital-twin-3d.md`） |
| 模型 | 自建工业模型资产库（`scene/assets/`）：统一米制尺度、统一材质库，零件用倒角盒、车削体、法兰螺栓圈、扫掠管拼装后按材质合并，每台设备只占几个绘制调用；不加载 GLB（没有授权清楚、尺度一致的 HVAC 模型集，且文件体积和加载时间与性能指标冲突） |
| 画面 | 正交相机、等距角度（方位 45°、俯角约 35°）的建筑沙盘；程序化环境光 + 一盏日光（阴影图按布局只画一次）+ N8AO 环境光遮蔽 + Neutral 色调映射。冷冻水为主色（蓝），冷却水为 chart-2（青绿），其余为浅灰白、暖白、金属银 |
| 文案 | 场景标签和侧栏只用业务词，不显示编码、UUID |

## 性能（硬指标）

- 3D 代码只在进入「数字孪生」页时加载（路由级拆包）；其他页面的包体积不变。
- 静止时不重绘：没有流动、没有交互时按需渲染（`frameloop="demand"`），数据变化时才刷新一帧；有流动时才持续绘制。
- 像素比上限 1.5；重复的设备用实例化或共享几何体与材质；不加载贴图和模型文件；所有表面用标准材质，只编译少量着色器。
- 帧率守卫：动画期间中位帧时间低于约 15 fps 时，关闭 AO 后处理并把像素比降到 1。
- 页面隐藏或离开路由时停止绘制并释放 WebGL 资源。
- 验收：1440 宽度下首次进入页面到场景可交互 ≤ 2 s（本地网络），静止时 CPU 占用接近 0，3D 分包 gzip 后单独列出体积。

## 界面

- 路由 `/digital-twin`（站点范围，`?site=`），侧栏「运行」分组下，名称「数字孪生」。
- 一个面板（`Panel`）：标题栏「站点三维视图」带 ⓘ 操作说明和「实时运行 ›」；工具栏放视角、楼层、外立面、突出管路的分段控件与图例；中间是场景；底部指标条：冷站总功率、瞬时制冷量、冷站 COP、室外温度、室外湿球（摘要，归属页是实时运行）。画布上只有场景标签，不叠浮动卡片。
- 点选设备由 `?inspect=` 打开右侧详情栏：有数据的设备用设备页的设备侧栏（设备 id），未接入的资产显示名称、类型和「未接入」（资产 id）。
- 视角按钮：全景 / 冷站 / 末端；楼层：全部楼层 / 3F / 2F / 1F（剖切到该层）；开关：外立面、管路（突出管路，其余变淡）。视角、楼层与开关都在 URL（`view`、`floor`、`shell=off`、`pipes=on`）。
- 深色主题下场景颜色取深色令牌。
