# 集成管理：现场网关、电表逐时质量核对与传感器零点校准工作台

问题单 #790（子单 #791、#792、#793；路线图 #757）。2026-11-12 已实现。

上游数据质量与测量不确定度基础见 `docs/specs/telemetry-data-quality.md`（#750、#751）与 `docs/specs/measurement-uncertainty.md`（#752）。

系统管理员与运维工程师在核对冷站底层采集质量时面对三层不同的问题：现场网关（如松雅轩 Node-RED 网关）的证书是否有效、总电表与机组分表的累计读数近 24 小时有没有跳变或断档、供回水温度探头与流量功率传感器有没有零点偏移或小温差低可信问题。原来 `/settings/integrations` 只展示现场网关证书，电表和传感器的质量标记散落在设备详情侧栏里，没有集中的核对与派单入口。

## 定下来的做法

| 问题 | 做法 |
| --- | --- |
| 数据归谁管 | 不新增重复的数据表，严格复用既有模块事实源：现场网关证书归连接模块（`/api/v1/gateways/{id}/credential`）；设备、资产铭牌、传感器登记与点位配置归登记模块（`GET /api/v1/sites/{siteId}/asset-model`）；点位实时健康度、物理一致性原因码、测量不确定度区间（`measurement`）与仅水泵运行稳态探头零点建议（`probeOffsets`）归遥测快照（`POST /api/v1/telemetry/observation-snapshots:batchGet`）；逐时电量核对对比能耗序列（`POST /api/v1/analytics/energy-series`，`granularity: 'hour'`）的 `VALID_ONLY` 与 `VALID_AND_SUSPECT` 两条口径；现场核查与校准闭环归工单模块（`EXTERNAL` 来源引用） |
| 治理红线（不改原始读数） | 网页端绝不提供手工覆盖历史电量或直接改写原始温度曲线的按钮。可疑电量跳变仅标出差值供现场核查，换表、脉冲倍率调整或通信寄存器变更走站点接入清单（`scripts/site-onboarding.mjs`）；供回水探头零点偏差明确标明「未采用」，现场核实探头插入深度、导热硅脂与变送器零点后再修正硬件或站点标定配置 |
| 页面怎么分层 | `/settings/integrations`（侧栏「平台」分组）按 `?view=gateways\|meters\|sensors` 分三个一级页签，单台设备或单个点位的深入诊断收进右侧 `?inspect=<key>` 抽屉（480px），默认进入「现场网关」页签时不额外请求遥测快照与能耗序列 |
| 现场网关页签（`gateways`） | 保留五段式「数据链路」（现场设备 → 现场网关 → 平台服务 → 站点目录 → 实时推送）与现场网关列表、一次性接入码生成及永久停用二次确认弹窗，抽屉开关同步到 `?inspect=<gatewayCode>` |
| 电表数据核对页签（`meters`） | 顶部展示 3 项指标（已接入表计、有效计量时段 `有效 / 已结束小时`、待现场确认台数，口径说明收进 `ⓘ`）；中部「近 24 小时逐时电量核对」用堆叠柱状图对比有效电量与可疑差值电量（配 `[图表 \| 表格]` 视图切换，缺读数时段如实画斜线占位并标为 `缺数据`，当前未结束整点标为 `当前小时统计中`）；底部 `计量表计` 表严格 5 列（表计与位置、24 小时状态条、近 24 小时计量、当前累计读数、状态与操作），覆盖总电表、总冷量表、流量计与带累计电表点位的设备控制器。点开右侧抽屉可看通信通道、采样周期、回零/翻转规则、中文异常解释、24 小时逐时增量图/表、一键跳转「历史趋势」查看瞬时曲线，以及自动去重的「创建核查工单」（`integrations-meter:{siteId}:{deviceCode}`） |
| 传感器校准页签（`sensors`） | 顶部展示 4 项指标（已接入数值点位、零点偏移建议 `N 项 · 未采用`、物理与低可信提醒、定检到期——站点未录入 `calibrationDueAt` 时如实显示 `未登记`，绝不伪造 `0 项逾期`）；`点位与传感器` 表支持「全部点位 / 待关注 / 零点建议 / 定检到期」筛选，严格 5 列（点位与设备、当前读数、零点建议 / 不确定度、定检到期、状态与操作）。点开右侧抽屉展示物理传感器厂家型号序列号、绑定设备铭牌额定功率/制冷量基准、仅水泵稳态窗口零点偏移详情（如 `建议减去 0.38 K · 未采用`）、派生量测量不确定度区间（如 `低可信 · ±28%（295.3–529.7 kW）`，小温差相对误差超 10% 时自动剔除 COP 均值、故障诊断、小时供冷与节能验证）、24 小时逐时均值图/表、跳转「历史趋势」链接，以及自动去重的「创建校准工单」（`integrations-sensor:{siteId}:{deviceCode}:{pointCode}`） |
| 状态与无障碍 | 所有治理状态徽章同时带几何形状与文字（`◆` 通信中断/读数无效/定检超期、`▲` 待现场确认/零点待校核/低可信提醒、`■` 等待读数、`○` 计量正常/读数正常），不单靠颜色区分；每张图表均配 `[图表 \| 表格]` 切换 |

## 验收与测试接缝

1. **前端核对与校准纯模型接缝（`npm run web:model:test`）**：
   - 验证 `VALID_ONLY` 与 `VALID_AND_SUSPECT` 逐时差值与缺段统计、表计分类（总电表 / 总冷量表 / 流量计 / 设备电表）、回零与模数翻转文案、14 类质量与物理原因码中文解释、探头零点正负号与「未采用」提示格式化、测量不确定度区间格式化、传感器定检到期状态（未登记 / 有效 / 临期 / 超期）、`EXTERNAL` 工单按 `sourceRef` 去重匹配、以及网关错误中文转换。
2. **浏览器 1440px 端到端验收（`npm run web:e2e`）**：
   - 验证 `gateway-credentials.spec.ts` 原有接入码与停用确认回归通过；验证 `integrations.spec.ts` 在 `1440×900` 视口下三个页签零横向溢出、URL `?view=` 与 `?inspect=` 状态同步、逐时电量核对 `[图表 | 表格]` 切换、表计抽屉与传感器校准抽屉展示治理说明与趋势深链、以及计量核查工单与传感器校准工单创建后自动切换为「查看核查工单 / 查看校准工单」。
