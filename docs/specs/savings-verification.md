# 节能项目与节能验证（M&V）

问题单 #484。2026-10-12 和用户分三轮定下第一版（按冷站总表统计），2026-10-13 定下第二版（按单台设备的分表统计）。两版都已上线，并在重放的历史上验收过（见 `docs/HANDOFF.md` 的本地环境一节）。

名词按 IPMVP（国际节能效果测量和验证规程）：措施、测量边界（在哪块电表上量）、基线期（措施实施前用来拟合基线的那段时间）、报告期（实施后统计节能的那段时间）、调整后基线、节电量，见 `GLOSSARY.md`。

## 定下来的做法

| 问题 | 做法 |
| --- | --- |
| 措施从哪来 | 用户在「节能项目」页登记；可以关联一条已经执行的优化建议或控制指令作为依据 |
| 在哪块电表上量 | 登记时选：冷站总表（IPMVP 方法 C），或某台有分表的设备（方法 B）。只列出有分表的设备；登记后不能改 |
| 基线怎么算 | 按小时做线性回归：用电 = a + b × 冷站供冷量（天气变化大时可以再加一项冷却度时）。总表边界用冷站用电，设备边界用这台设备的用电，供冷量都用冷站的。必须通过 ASHRAE Guideline 14 的检验，否则显示「基线不可信」，不出节能数字 |
| 基线期和报告期 | 基线期默认是实施前 14 天（至少 72 个完整小时、数据覆盖 90% 以上）；实施后头 24 小时是稳定期，不算；之后每天统计，按日、按月汇总 |
| 电费 | 每小时的节电量 × 这个小时的估算电价（Cube 给出的这个小时电费 ÷ 计价电量，见 `docs/specs/estimated-energy-cost.md`）。没有电价的小时只算电量，不算电费，页面注明有几小时没计入。需量电费的节省不算，页面上注明 |
| 由谁负责 | `mv-service`（和预测、优化、故障诊断服务并列）。它保存措施、固定下来的基线和每天的统计结果；定时任务 `MV_EVALUATION` 每天 02:00 统计前一天 |
| 权限 | 登记、确认实施、结束、重新拟合需要「节能项目管理」（`savings.manage`），默认给管理员；查看只要站点的查看权限 |
| 状态 | 计划中 → 已实施 → 已结束 |
| 基线固定 | 确认实施时，用基线期拟合并固定下来。没通过检验，可以换一段基线期重新拟合，直到第一天的统计结果发布为止；之后基线不能改 |
| 时间重叠 | 同一台设备上的措施，报告期不能重叠；不同设备上的可以重叠；总表上的措施和任何措施都不能重叠（总表包含了所有分表）。重叠的登记会被拒绝并说明原因；几项改动可以合成一个措施登记。数据库触发器执行同一条规则 |
| 页面 | 能源分组的「节能项目」页：措施列表、登记、详情侧栏（基线检验结果、每天的节电量、每天实际用电和调整后基线、累计节电量和节省电费）；总览有「节能成效」；月度报告有「节能成效」一节 |

## 怎么运作

1. **登记**：名称、类型、计划实施时间、说明、测量边界（不选设备就是总表），可选填投资额、预计每年节电量、关联依据。状态为「计划中」。选的设备没有「设备逐时用电量」指标的，拒绝登记（「该设备没有逐时用电指标」）。
2. **确认实施**：填实际实施时间。服务读基线期每小时的用电和供冷量，拟合直线，算出 CV(RMSE) 和 NMBE。
   - 通过检验：固定系数、样本数、检验值和基线期，状态变为「已实施」。
   - 没通过：状态也变为「已实施」，但标「基线不可信」并记下检验值；可以换基线期重新拟合，直到第一天的统计结果发布。
3. **每天统计**：对每个已实施、基线可信的措施，取报告期里已经结束、又不在 24 小时稳定期内的每个小时：
   - 调整后基线 = a + b × 实际供冷量；
   - 节电量 = 调整后基线 − 实际用电；
   - 节省电费 = 节电量 × 这个小时的估算电价。

   按站点本地日加起来，写成这一天的结果，之后不再改。缺数据的小时算进覆盖率的缺口，不补。只用数据质量为「好」的小时：总表边界要冷站的小时用电和小时供冷量都好；设备边界还要这台设备的小时用电也好。
4. **结束**：填结束时间，之后不再统计。
5. **查看**：措施列表、措施详情（含基线检验和每天的结果）、站点本月的汇总。

数据来源：冷站小时用电 `hourly_energy`、小时供冷量 `hourly_cooling`、设备小时用电 `device_hourly_energy`（读这台设备分表的累计电量，每台有分表的设备一个，每小时算一次）。设备边界也读已发布的指标结果，而不是直接读分表，是为了守住 ADR 0021「节能验证读已发布的指标结果」。每天的结果还记下这些小时里冷站的总用电（`plantKWh`）。

## 站点汇总

总览、节能项目页的本月数字、月度和年度报告，把各措施的节电量和节省电费加起来。站点的节电率 = 节电量 ÷（同一批小时里冷站的实际用电 + 节电量）；同一天有几项措施时，冷站用电取其中最大的一条，不重复算。每项措施的详情仍按它自己的边界：节电量 ÷ 调整后基线。

## 检验门槛（ASHRAE Guideline 14，按小时的数据）

- CV(RMSE) ≤ 30%
- |NMBE| ≤ 10%
- 基线期至少 72 个完整小时，覆盖 90% 以上

## 还不做

需量电费的节省、非常规调整（例如建筑面积或使用时间变了）、多项措施之间分摊节电量、节能项目的审批流程。
