## 任务与层级

首页在 30 秒内回答：用多少、比基线省多少、节约多少钱、哪些策略有效、舒适度是否守住、下一步做什么。
页面使用现有 shadcn 应用外壳，内容最大宽度 1600px，桌面内边距 24px，模块间距 20px。默认审核视口为 1440×900 与 1920×1080。

| 顺序 | 内容与责任 | 组成 |
| --- | --- | --- |
| 1 | 标题、所选范围、期间、刷新、摘要导出 | Page Header；示例状态明确可见 |
| 2 | 日期、更新时间与数据方法；高后果告警优先提醒 | 上下文行、按事实出现的风险提示 |
| 3 | 实际用电、节省电量、节能率、节约费用 | 单一整体指标带，四列分隔；成果数字只在此汇总 |
| 4 | 看懂基线与实际的时间变化及计算依据 | 全宽双线趋势；口径详情入口，不另设重复成果卡 |
| 5 | 解释策略贡献与舒适度约束 | 两列同高、上下对齐；先精简说明，再按真实内容分配空间 |
| 6 | 明确可执行的节能机会与当前关注项 | 7:5；精简只读机会表与注意事项 |
| 7 | 用必要工程指标解释运行表现 | 一条系统指标带；不合成跨系统能效分数 |

## 数据与颜色语义

实际用电为蓝色，基线为中性灰。实际低于基线时使用浅绿差值区域；缺测不连线、不填零。功率 kW 与期间电量 kWh 分开；汇总不能由功率曲线直接冒充。
绿色用于正节省结果；负节能率以风险色表达，缺失值使用中性色与破折号。琥珀色用于真实舒适度偏离或待处理风险，不为普通模块装饰性着色。
基线方法、报告期间、范围、覆盖率、验证状态不能省略或编造。策略贡献标记为估算，存在重叠时不得相加宣称已验证全站收益。

## 交互与生命周期

期间与范围由 URL/TanStack Router 管理，数据由 TanStack Query 管理。返回恢复期间，跨专业工作区保留范围。
基线说明、策略证据和舒适度异常使用非模态快速详情 Sheet，不遮罩或挤压主页面；范围/期间改变关闭旧详情。正式分析和验证进入专业页面。
导出生成真实 CSV，包含范围、期间、示例/真实来源、待验证说明和缺失值。首页不以本地按钮状态冒充派工、策略执行或闭环成功。

## 生产与示例边界

DEV/frontend-review 明确显示示例数据，范围与期间变化产生相应数据。生产仅读取现有平台 dashboard-overview owner 的当前站点概况；尚无集团/区域历史聚合、基线方法及核证证据。未支持的范围或期间显示明确错误和恢复动作；接口失败不回退到示例。
实测舒适度与监测覆盖分开。未提供覆盖率、方法或证据的字段明确显示未知。

## 组件与验收

shadcn Card/Button/Badge/Sheet/Table/Chart 为唯一基础组件体系，Lucide 为业务图标。首页精简只读机会表不增加完整账本控制；专业账本仍遵循 tablecn/TanStack 规范。
采用 satnaing 的应用布局、arham 的整体指标层级、Kiranism 的 Chart/error composition；不迁移 Next.js/Base UI runtime，不照搬模板业务。
桌面浏览器必须验证期间/范围确实更新、返回恢复、详情关闭、CSV 下载和跨页范围保留。视觉验收关注层级、密度、图表读数与状态强调；构建通过不等于视觉通过。
本轮移除旧六卡指标、分项 Donut、Gauge、装饰性火花线、待办和数据质量拼盘的首页布局要求。

2026-09-30 用户精修：同排卡片边缘对齐。删去重复副标题、主页面解释性脚注与各模块的示例说明，仅保留标题旁一个来源标识。来源、方法、估算/核证口径在快速详情和导出中保留；主页面灰色用于次级对象、单位和必要状态，不用于每个模块的描述段落。

## 全页面职责审核（2026-09-30）

| 模块/入口 | 审核发现与调整 | 保留责任 |
| --- | --- | --- |
| 指标带 / 节能表现 | 四个汇总值重复，独立表现卡只增加一个节能率；删除该卡，节能率归入成果带 | 唯一期间成果汇总 |
| 指标带 / 舒适度 | 合规率重复；从成果带移除舒适度 | 舒适度卡集中显示合规、覆盖与超限区域 |
| 基线趋势 / 上下文 | 日期重复；图表副标题仅留单位，口径入口移入图表 Header | 图表解释时间变化，详情解释方法，专业分析负责调查 |
| 策略 / 机会 | 主题相关但生命周期不同，保留；标题不宣称已验证贡献 | 正在运行策略的估算贡献 / 尚未实施机会的潜力 |
| 机会标题 / 下一步 | 同一详情两个入口；标题改为普通文本，仅保留操作按钮 | 每行一个清楚的下一步 |
| 舒适异常 / 查看约束 | 每行都打开同一个整体详情；异常改为静态事实，仅保留查看约束入口 | 超限对象事实与整体证据详情 |
| 风险横幅 / 待处理事项 | 高风险提示与具体事项属不同层次，保留按事实出现的横幅 | 先提醒高后果，再定位具体工作 |
| 系统效率 / 节能成果 | COP、输送能效与风量功率不是节省指标，不重叠 | 工程运行解释，不混成综合评分 |

不增加新指标、目标完成度、节能评分或伪核证信息来填空。全页详情、导航与下载保持已有真实能力边界。
