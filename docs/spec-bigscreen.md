# 演示 / 汇报大屏模式 — 规格章节

> 对应 wayfinder 票 #9（grilling）。本文是「演示模式」规格章节，落地到真实 `/bigscreen` 路由时的设计契约。
> 前置：#2 IA（演示大屏为 10 模块之一 `/bigscreen`）、#5 RBAC（演示=READONLY/运维=MAINTENANCE/研发=ADMIN，演示模式可切真实只读/样例）、#6 设计语言（teal 单强调色 + 语义状态色 + 深浅双主题）、#7（优化成效数据来源）、#8（实时层，大屏样例数据用模拟波动）。

## 1. 定位与边界

- **独立全屏路由（平行分支）**：`/bigscreen` 是主 IA 下的一级入口，但进入后**全屏接管**——隐藏左侧栏与顶栏操作区，仅保留极简标题栏。它**不是**仪表盘 D 的放大版，是面向客户/领导/合作方的"节能收益叙事页"。
- **上下文继承**：仍从主壳继承 角色 / 建筑全局上下文 / `demoMode` 演示数据开关，不另起一套状态。
- **与日常仪表盘分工**：`/dashboard` = 运维/研发日常用（密度高、告警常驻）；`/bigscreen` = 投屏汇报用（精选叙事、自动轮播、强制深色）。
- **人在回路红线不变**：大屏**只读展示**，任何动作（提交审批/下发设备）都不在大屏出现；大屏不是操作界面。

## 2. 视觉与主题

- **强制深色主题**：进入大屏忽略系统 `prefers-color-scheme`，强制 dark（投影观感最稳）；沿用 #6 teal 单强调色 + 语义状态色，圆角锁一致。
- **隐藏鼠标**：进入后鼠标闲置 3s 自动隐藏（`cursor:none`），移动即显，避免投屏时指针抢戏。
- **ESC 退出**：按 ESC 回到主壳 `/dashboard` 或来时页面。
- **极简标题栏**（顶部细条）：建筑名 + 「演示」标识 + 场景进度点（当前第几个场景）；不显示通知铃铛/用户/设置等操作控件。

## 3. 内容精选（叙事视图，非全量镜像）

不堆运维指标，只讲"节能收益"故事。三类元素：

1. **英雄 KPI 区**：今日能耗、综合 COP、累计节能（¥）/（kWh）——大数字 + 同比/环比箭头。COP 用 teal 主视觉卡（沿用 D 的聚焦语言）。
2. **能耗趋势 + 分区环比**：日/周/月面积图（teal 单色），下方园区/分区能耗条形或环形对比；点明"哪栋楼最省 / 哪段时段峰值"。
3. **优化成效**：来自 #7 `/optimize` 的已批准建议累计收益（节能量/费用/碳排），以"已帮您省下"叙事呈现；可配轻量成就列表。

- **告警弱化**：大屏**不显示原始告警流**；仅顶部一条健康度（如"系统运行正常 · N 项优化进行中"）。汇报不暴露运维噪音。
- **数据形状对齐**：KPI/趋势/分区来自 `telemetry`（`latest/batch` + `timeseries`，见 #8）；优化成效来自 `/optimize` 已批准集合（#7）。

## 4. 叙述流与动效

- **自动轮播场景**：2~3 个场景按计时切换，默认每 **15s** 一幕：
  - 场景 1 · 总览：英雄 KPI 英雄区
  - 场景 2 · 能耗：趋势 + 分区环比
  - 场景 3 · 成效：优化收益故事
- **可控**：标题栏提供 暂停/播放 + 上一幕/下一幕；手动操作后暂停自动轮播（或重置计时）。
- **轻微实时脉冲**：样例数据下 KPI 数字带 ±轻微随机波动（每 2~3s 微动），图表末端 point 呼吸，制造"活着"的实时感（不依赖 WS，纯前端模拟，见 #8 降级思路）。
- **过渡**：场景切换用淡入+轻微位移（尊重 `prefers-reduced-motion`，降级为瞬切）。

## 5. 数据来源

- **默认样例数据**：进大屏**自动开 `demoMode`**（保证故事干净好看、不依赖后端真实数据是否"漂亮"）。
- **可切真实**：提供「切真实数据」开关（大屏内或主壳顶栏均可）；切真后读 `telemetry` REST（#8 契约），若 WS 可达则接实时层。
- **样例数据策略**：`src/mock` 大屏专用样例集，带确定性"好故事"基线 + 轻微随机波动模拟实时；形状与真接口一致，切真零改结构。

## 6. 入口与退出

- **入口**：主壳侧栏「演示大屏」(`/bigscreen`，演示/运维/研发可见，沿用 #2 角色可见性) + 顶栏快捷按钮（一键进大屏）。
- **退出**：ESC 键，或标题栏「退出」；回到进入前的页面。

## 7. 跨切面

- **角色可见性**：`/bigscreen` 演示/运维/研发均可见（#2 矩阵：演示=总览/大屏只读，运维/研发含大屏）。大屏内无写操作，RBAC 仅影响能否从主壳进。
- **设计语言**：沿用 #6（teal + 语义色 + 深浅，此处强制深）。
- **适配**：大屏按 **16:9 横屏投影** 设计（1366×768 起，向上 1080p/4K 自适应栅格）；移动端不在本票范围（见地图迷雾"移动端适配"）。
