# 智慧能源系统配置中心与版本发布设计

> 版本：V1.0  
> 技术基线：Go + PostgreSQL + Redis + MQTT + Edge Gateway  
> 目标：让关键配置具备可版本化、可审批、可灰度、可回滚、可追溯、可审计能力。

---

## 1. 配置中心定位

智慧能源系统中的配置会直接决定：

```text
设备怎么采
数据怎么解释
告警怎么触发
指标怎么算
控制是否允许
Edge怎么运行
```

因此正式配置必须走统一生命周期：

```text
Draft
→ Validate
→ Test
→ Approve
→ Release
→ Rollout
→ Observe
→ Complete / Rollback
```

PostgreSQL 是配置 Source of Truth；Redis 只保存运行态缓存；Edge 只保存已发布配置的本地副本。

## 3. 生命周期

统一状态：

```text
DRAFT
VALIDATING
TESTING
READY
APPROVED
RELEASED
ROLLING_OUT
ACTIVE
PAUSED
ROLLBACK
DEPRECATED
RETIRED
```

### DRAFT

允许编辑，禁止生产使用。

### VALIDATING

执行：

```text
Schema
Reference
Type
Unit
Range
Duplicate
Dependency
Compatibility
Permission
```

### TESTING

允许：

```text
Simulator
Test Environment
Bench Device
Shadow
```

### APPROVED

高风险资源必须审批。

### RELEASED

正式版本不可修改。任何内容变化必须创建新版本。

---

## 4. 版本模型

所有版本对象至少包含：

```text
resource_type
resource_id
version
revision
schema_version
checksum
status
created_by
approved_by
released_at
```

建议正式版本使用：

```text
MAJOR.MINOR.PATCH
```

### MAJOR

破坏兼容：

```text
Point语义改变
Command语义改变
MQTT Schema破坏兼容
```

### MINOR

向后兼容新增：

```text
新增Point
新增可选字段
新增Command
```

### PATCH

非语义修复。

---

## 5. 不可变发布

RELEASED 版本必须：

```text
Immutable
```

禁止：

```text
UPDATE released config
```

修改流程：

```text
Clone
→ Edit
→ Validate
→ Release New Version
```

每个正式版本计算：

```text
SHA-256 checksum
```

用于 Edge 完整性校验和 Desired/Reported 比较。

```text

```

```text

→ 多Site
→ 全量
```

## 15. Alarm Rule 发布

推荐生命周期：

```text
DRAFT
→ BACKTEST
→ SHADOW
→ ACTIVE
```

Backtest 从 ClickHouse 读取历史数据，验证：

```text
Trigger Count
False Positive
Duration
Recovery
Storm Risk
```

Shadow 阶段：

```text
计算
但不产生正式Alarm/通知
```

---

## 16. Metric 发布

Metric Definition 位于 PostgreSQL。

Metric Result 在 ClickHouse 必须携带：

```text
metric_version
binding_version
calculation_run_id
revision
```

修改 Metric 后必须明确：

```text
Future Only
```

还是：

```text
Historical Recalculation
```

重算必须生成新的 Revision，禁止静默覆盖历史结果。

## 17. Safety Policy 发布

属于高风险配置。

至少要求：

```text
双人审批
```

Risk 4 可要求：

```text
MFA
```

例如修改：

```text
SOC Limit
Max Charge Power
Max Discharge Power
Temperature Limit
Interlock
Control Mode
```

发布前需要：

```text
Simulation
Shadow
Impact Review
```

---

## 18. 安全配置回滚特殊规则

例如紧急将：

```text
Max Discharge Power
500kW → 300kW
```

属于安全收紧。

即使部分节点应用失败，也不能因为通用发布机制自动：

```text
全局恢复到500kW
```

安全类发布必须支持：

```text
rollback_policy = MANUAL_ONLY
```

## 19. Tariff / Carbon Factor



## 23. Pause / Abort / Rollback

### Pause

停止后续目标，已成功目标保持当前版本。

### Abort

停止发布，不自动回滚成功目标。

### Rollback

生成新的正式发布记录：

```text
rollback_from
rollback_to
reason
operator
```

支持：

```text
Single Gateway
Single Device
Single Site
Global
```

---

## 24. 自动回滚

可以基于：

```text
Crash Loop
Device Offline Rate
Poll Error Rate
Config Apply Failure
MQTT Disconnect
CPU / Memory
```

触发。

示例阈值：

```text
apply failure > 5%
device offline increase > 10%
poll error x3
gateway crash > 2
```

安全和紧急修复类配置可以禁用通用自动回滚。
