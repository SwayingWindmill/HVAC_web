# 智慧能源系统整体规划总结

智慧能源系统不是单纯的 IoT 系统，而是以 IoT 为基础，融合能源数据管理、EMS、预测分析、优化调度和自动控制形成的一套能源数字化平台。

其核心目标不是“把数据展示出来”，而是实现完整的能源管理闭环：

**感知 → 采集 → 建模 → 分析 → 预测 → 优化 → 控制 → 反馈**

最终让能源系统从“可见”发展到“可分析、可预测、可优化、可控制”。

## 一、整体系统架构

智慧能源系统可以规划为七个主要层级：

**1. 设备层**

包括：

- 智能电表、水表、气表
    
- 光伏逆变器
    
- 储能 PCS、BMS
    
- 充电桩
    
- 空调、冷机、水泵
    
- 温湿度等环境传感器
    
- 其他能源及用能设备
    

设备层负责能源生产、消费、储存以及现场状态感知。

**2. 边缘与 IoT 接入层**

负责现场设备的数据采集与控制接入，支持：

- Modbus RTU/TCP
    
- BACnet
    
- OPC UA
    
- MQTT
    
- IEC 104
    
- 其他工业协议
    

边缘网关承担协议转换、数据缓存、断点续传、数据预处理以及部分本地控制。

**3. 能源数据平台**

这是整个智慧能源系统的数据基础。

主要建立：

- 设备模型
    
- 测点模型
    
- 组织空间模型
    
- 能源类型模型
    
- 时序数据模型
    
- 能源拓扑模型
    
- 标签体系
    
- 数据质量体系
    

系统不能只是记录一个简单的：

`Power = 500`

而应该知道：

`哪个园区 → 哪栋建筑 → 哪台设备 → 哪个测点 → 什么指标 → 什么单位 → 什么时间 → 数据质量如何`

因此，统一数据模型是智慧能源平台最重要的基础能力之一。

## 二、能源业务平台 EMS

EMS 负责把底层能源数据转化为实际业务能力。

主要包括：

- 能耗统计
    
- 分项能源计量
    
- 能源成本分析
    
- 电费分析
    
- 峰谷分析
    
- 最大需量管理
    
- 能效 KPI
    
- 碳排放统计
    
- 能源报表
    
- 异常告警
    
- 设备运行分析
    

这一阶段主要回答三个问题：

**能源在哪里产生？**

**能源在哪里消耗？**

**能源花了多少钱？**

## 三、预测与智能分析

在稳定的数据基础上，可以逐步建设智能分析能力，包括：

- 负荷预测
    
- 光伏发电预测
    
- 电价预测
    
- 能源成本预测
    
- 能耗异常检测
    
- 设备异常检测
    
- 能效分析
    
- 能源基线分析
    

系统开始从：

**“发生了什么？”**

升级到：

**“为什么发生？”**

以及：

**“接下来可能发生什么？”**

## 四、能源优化调度

进一步建设能源优化引擎。

典型应用包括：

- 储能充放电优化
    
- 削峰填谷
    
- 峰谷套利
    
- 需量控制
    
- 光储协同
    
- 充电桩有序充电
    
- HVAC 优化控制
    
- 需求响应
    
- 综合能源调度
    

例如：

系统预测明天 24 小时的用电负荷和光伏发电量，再综合：

- 电价
    
- 电池 SOC
    
- 储能容量
    
- 最大功率
    
- 用电需求
    
- 需量约束
    

计算储能什么时候充电、什么时候放电，从而降低能源成本。

## 五、自动控制系统

智慧能源系统与传统能源 BI 系统的重要区别，是智慧能源系统最终可以形成控制闭环。

基本逻辑为：

**数据采集 → 分析 → 预测 → 优化 → 控制指令 → 设备执行 → 状态反馈**

控制对象可以包括：

- PCS
    
- 储能系统
    
- 充电桩
    
- 空调
    
- 冷机
    
- 水泵
    
- 光伏设备
    
- 其他可控负荷
    

但自动控制不能直接由 AI 或优化算法操作设备。

中间应该增加：

- 安全规则
    
- 控制权限
    
- 最大/最小限制
    
- 人工/自动模式
    
- 指令审核
    
- 执行确认
    
- 状态反馈
    
- 控制日志
    

保证能源系统安全运行。

## 六、核心数据模型

平台建议建立统一的组织和资产结构：

`Tenant 租户`  
`↓`  
`Site 园区`  
`↓`  
`Building 建筑`  
`↓`  
`Area 区域`  
`↓`  
`Device 设备`  
`↓`  
`Point 测点`

同时建立能源类型：

- 电
    
- 水
    
- 气
    
- 冷
    
- 热
    
- 蒸汽
    

以及能源系统：

- 市电
    
- 光伏
    
- 储能
    
- 充电桩
    
- HVAC
    
- 其他负荷
    

还需要建立能源拓扑，例如：

`变压器`  
`↓`  
`低压柜`  
`↓`  
`配电柜`  
`↓`  
`回路`  
`↓`  
`电表`  
`↓`  
`设备`

只有建立这些关系，系统才能真正回答：

- 一个园区用了多少能源？
    
- 一栋楼用了多少电？
    
- 哪个回路能耗异常？
    
- 空调用电占比多少？
    
- 光伏发了多少电？
    
- 光伏自用率是多少？
    
- 储能节省了多少钱？
    
- 明天负荷是多少？
    
- 储能应该如何调度？
    

## 七、推荐技术架构

整体可以采用：

**现场设备**

↓

**Edge 边缘网关**

↓

**IoT 平台**

↓

**能源数据平台**

↓

**EMS 业务平台**

↓

**AI / 优化决策平台**

↓

**Web / App / 能源驾驶舱**

数据基础设施可以采用：

**PostgreSQL**

负责：

- 设备
    
- 组织
    
- 用户
    
- 权限
    
- 配置
    
- 业务数据
    

**ClickHouse**

负责：

- 功率
    
- 电压
    
- 电流
    
- SOC
    
- 温度
    
- 流量
    
- 其他高频时序数据
    

**Redis**

负责：

- 实时设备状态
    
- 缓存
    
- 高频访问数据
    

**MQTT / Kafka**

负责：

- 实时数据传输
    
- 数据流处理
    
- 系统解耦
    

**对象存储**

负责：

- 文件
    
- 报告
    
- 原始数据
    
- AI 模型
    
- 大规模历史数据
    

## 八、系统建设阶段

智慧能源平台不建议一次性建设全部功能，而应该分阶段推进。

### 第一阶段：数据打通

建设：

- 设备接入
    
- IoT
    
- 边缘网关
    
- 设备模型
    
- 测点模型
    
- ClickHouse
    
- 数据质量体系
    

目标：

**让所有能源数据稳定、准确、标准化地进入平台。**

### 第二阶段：能源可视化与 EMS

建设：

- 能耗统计
    
- 能源流向
    
- 电费分析
    
- 峰谷分析
    
- 告警
    
- 报表
    
- 能源驾驶舱
    

目标：

**把能源看清楚。**

### 第三阶段：智能分析

建设：

- 能耗异常
    
- 设备异常
    
- 能效分析
    
- 能源基线
    
- 需量预警
    
- 光伏效率分析
    
- 储能效率分析
    

目标：

**让系统开始主动发现问题。**

### 第四阶段：预测

建设：

- 负荷预测
    
- 光伏预测
    
- 电价预测
    
- 成本预测
    
- 设备状态预测
    

目标：

**让系统知道未来可能发生什么。**

### 第五阶段：优化控制

建设：

- 储能调度
    
- 削峰填谷
    
- 需求响应
    
- 需量控制
    
- 充电桩调度
    
- HVAC 优化
    
- 综合能源优化
    

目标：

**让系统自动给出最优能源运行策略，并在安全规则下执行。**

## 九、智慧能源系统的核心

智慧能源系统最终应该形成：

**IoT + 能源数据底座 + EMS + AI预测 + 优化调度 + 自动控制**

其核心能力可以概括为：

**Observe → Analyze → Predict → Optimize → Control**

即：

**感知 → 分析 → 预测 → 优化 → 控制**

智慧能源系统真正的“智慧”，并不只是大屏或者 AI，而是建立在统一能源数据体系上的持续优化能力。

## 十、建设优先级

如果从零开始建设智慧能源平台，建议优先级为：

**数据模型**  
↓  
**IoT 接入稳定性**  
↓  
**能源业务模型**  
↓  
**能源数据平台**  
↓  
**EMS**  
↓  
**预测与优化算法**  
↓  
**AI**  
↓  
**可视化大屏**

核心原则是：

**先把数据和模型做正确，再做应用；先解决能源管理问题，再做 AI。**

一个优秀的智慧能源平台，最终应该成为企业的**能源数字底座**。

在这个底座之上，可以不断扩展：

- 光伏
    
- 储能
    
- 充电
    
- HVAC
    
- 碳管理
    
- 微电网
    
- 需求响应
    
- 虚拟电厂 VPP
    
- 综合能源管理
    

因此，智慧能源平台长期真正有价值的不是某一个功能，而是：

**统一能源数据模型 + 时序数据平台 + 设备模型 + 能源业务模型 + 优化控制引擎。**
