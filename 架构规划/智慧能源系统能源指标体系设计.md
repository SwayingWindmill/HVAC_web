# 智慧能源系统能源指标体系设计

## 一、设计目标

点位标准解决的是：

**设备采集什么数据。**

能源指标体系解决的是：

**这些数据在业务上代表什么、怎么计算、怎么比较、怎么评价。**

例如设备上传：

```text
active_power = 2350 kW

energy_import = 182736.5 kWh

pv_power = 650 kW

soc = 62%
```

这些属于 Point。

但管理者真正关心的是：

```text
今天用了多少电？

今天花了多少钱？

最大需量是多少？

光伏覆盖了多少负荷？

储能节省了多少钱？

单位产量能耗是多少？

本月碳排放是多少？
```

这些属于 Metric。

因此整个指标体系建立在：

```text
Point
 ↓
Telemetry
 ↓
Aggregation
 ↓
Metric
 ↓
KPI
 ↓
Analysis / Optimization
```

这一条链路上。

---

# 二、核心原则

能源指标体系建议遵循以下原则：

## 1. Point 与 Metric 分离

Point 是设备语义。

例如：

```text
active_power
energy_import
soc
temperature
```

Metric 是业务语义。

例如：

```text
daily_energy
energy_cost
peak_demand
pv_self_consumption_rate
ess_revenue
```

---

## 2. 指标必须标准化

不能不同项目分别定义：

```text
日用电
今日用电
今天电量
daily_power
day_energy
```

统一：

```text
daily_energy
```

---

## 3. 指标必须可追溯

任何指标必须知道：

```text
Metric
 ↓
Formula
 ↓
Source Point / Metric
 ↓
Device / Asset
```

---

## 4. 指标必须有时间粒度

例如：

```text
energy_consumption
```

本身是不完整的。

必须知道它是：

```text
15分钟
小时
日
月
年
```

---

## 5. 指标必须有明确单位

例如：

```text
energy_cost
```

必须定义：

```text
CNY
```

```text
daily_energy
```

必须：

```text
kWh
```

---

## 6. 指标计算必须考虑数据质量

如果输入数据：

```text
70% GOOD
30% MISSING
```

计算出来的指标不能直接标记为：

```text
GOOD
```

---

## 7. 指标公式必须版本化

例如电费规则、电价规则、碳排放因子都会变化。

必须知道：

```text
这个指标是按照哪个规则版本计算的。
```

---

# 四、Metric Definition 标准模型

每一个指标至少应该定义：

```text
metric_code

metric_name

category

description

unit

data_type

subject_type

time_granularity

aggregation

calculation_method

formula

input_metrics

input_points

quality_policy

version

status
```

例如：

```yaml
metric_code: daily_energy
metric_name: 日用电量
category: ENERGY
unit: kWh
time_granularity: DAY
calculation_method: COUNTER_DELTA
source_point: energy_import
quality_policy: STRICT
version: 1.0
```



某园区日用电量。

```text

```

```text

```

某楼层日用电量。

# 十三、功率积分模式

如果没有可靠累计电量，也可以：

```text
Energy
=
∫ Power dt
```

离散数据中：

```text
Energy
≈ Σ Power × Δt
```

例如：

5分钟平均功率：

```text
100 kW
```

持续：

```text
5 min
```

能量：

```text
100 × 5/60

= 8.33 kWh
```

# 五十、光伏消纳率

```text

```

```text

=

/
pv_generation
```

这一点必须在指标标准文档中固定。

# 一百七十八、最终设计原则

能源指标体系最终建议坚持十条原则：

**第一，Point 和 Metric 分离。**

Point 是设备语义，Metric 是能源业务语义。

**第二，每一个指标必须只有一个明确标准定义。**

避免同名不同义或者同义不同名。

**第三，所有指标必须带单位和时间粒度。**

没有时间边界的能源指标是不完整的。

**第四，指标必须能够追溯到源数据。**

Metric → Point → Device。

**第五，指标计算必须考虑数据质量。**

错误数据不能自动变成正确 KPI。

**第六，Counter、Power、State 必须采用不同聚合策略。**

不能所有数据都 SUM 或 AVG。

**第七，财务、碳和关键运营指标必须版本化。**

电价、碳因子和算法变化不能破坏历史解释能力。

**第八，迟到数据必须支持指标重算。**

断网补传是能源现场的正常情况。

**第九，结算型数据必须支持 Snapshot 和 Revision。**

保证财务和审计稳定性。

**第十，指标体系必须与 Point Standard、Energy Topology、Tag、AI 和 Optimization 共用同一套语义。**
